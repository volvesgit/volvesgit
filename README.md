### Hi, I'm VOLVES 👋

**Full-stack & automation engineer — I build AI-powered tools for the factory floor.**

I take problems from production lines and ship software operators actually use every day: from the database schema to the tablet UI, the Docker deployment and the printer or scanner at the end of the cable. Background in cybersecurity, so things are deployed hardened by default.

- 🏭 Industrial web apps wired to label printers, barcode scanners, MES/ERP and CAN-bus hardware
- 🤖 Applied AI: LLM agents, OCR + LLM extraction pipelines, local models (Ollama) when data can't leave the plant
- 🛡️ MSc in Cybersecurity · co-organizer of the **Hack'OSINT** CTF (700+ players) with [Hack'olyte](https://github.com/HACK-OLYTE)

#### 🔧 Built at work *(code is private)*

| Project | What it does | Stack |
|---|---|---|
| **PalletOptix** | 3D pallet-load optimization: bin-packing solver + interactive 3D viewer for logistics teams | FastAPI · React · Three.js · Docker |
| **LabelFlow** | Multi-printer, multi-template label printing for industrial CAB printers, driven from CSV production data | Python · React · Docker |
| **OCR Forms** | Tablet inspection forms that read documents and barcodes with OCR + LLM field extraction | FastAPI · React · Tesseract · Gemini |
| **MCU Flash Station** | Production-line ECU flashing over CAN (UDS / ISO-TP, seed-key unlock) on Vector interfaces, with an operator GUI and one-click deployment to shop-floor PCs | Python · python-can · PyInstaller |
| **E-Bike Service Tool** | Technician app for e-bike drive systems: live BLE telemetry, frame decoding driven by per-controller YAML profiles | Flutter · Dart · BLE |
| **CAN Tech** | Android CAN-bus analyzer: DBC decoding, log analysis and live listen-only capture through a USB slcan adapter | Flutter · Dart · USB serial |
| **Nexora CRM** | Full-stack CRM rebuild: JWT + RBAC auth, PDF generation, AI-written interaction summaries | FastAPI · React 19 · PostgreSQL |
